1. INTRODUCTION                                *vantage.nvim-introduction*

Vantage runs coding agents (Claude Code, Codex, dsh, …) in tmux and shows them
in a single persistent `:terminal`. Multiple Neovim instances can show
different Agents in the same Group.

==============================================================================
2. REQUIREMENTS                                *vantage.nvim-requirements*

- Neovim >= 0.10
- tmux 3.0+

==============================================================================
3. INSTALLATION                                *vantage.nvim-installation*

With lazy.nvim: >

    {
      "ZachVec/vantage.nvim",
      cmd = "Vantage",
      opts = {},
    }

<
The plugin loads on the first `:Vantage`.

4. CONFIGURATION                              *vantage.nvim-configuration*

`setup()` accepts: >

    require("vantage").setup({
      backend = "tmux",          -- only "tmux" today
      socket = "vantage",        -- private tmux socket
      picker = "native",         -- native | fzf-lua | snacks

      prompts = {                -- add or override prompt templates
        ["{file}"] = "{file}",
        ["{line}"] = "{line}",
        ["{reviews}"] = "{reviews}",
      },

      reviews = {
        item = "{lines} {note}", -- per-review template
        clear_on_send = true,    -- clear reviews after sending {reviews}
        float = { style = "inherit" }, -- "inherit" | "minimal"
      },

      gather = {
        join = "\n",             -- separator between gathered references
      },

      cli = {
        tools = {},              -- name -> { cmd = { ... } }
        win = {
          layout = "float",      -- float | full | left | top | bottom | right
          float = { width = 1.0, height = 1.0, border = "none" },
          split = { width = 80, height = 20 },
          keys = {},             -- no default keymaps
        },
      },
    })

<
An unknown or unavailable `backend`/`picker` is an error at setup.

TOOLS ~

`cli.tools` is empty by default. Each Tool is an argv array: >

    require("vantage").setup({
      cli = {
        tools = {
          claude = { cmd = { "claude" } },
          codex = { cmd = { "codex", "--full-auto" } },
        },
      },
    })

<
A Tool needs a non-empty name, a non-empty `cmd`, and an executable first
element. Invalid entries are reported by `:checkhealth vantage`. The Agent
working directory is Neovim's global cwd (`:cd`; not `:lcd`/`:tcd`). A Tool may
also define `format(file, loc)`, the reference formatter: `file` is a path
relative to the Agent's cwd (absolute when it escapes) and `loc` the `:L`
position suffix, or nil for a whole-file reference.

PROMPTS ~

`prompts` maps names to templates. The built-in names are `{file}`, `{line}`,
and `{reviews}`; user entries merge with them. The `prompt` terminal key picks
a prompt and types it into the focused Agent without submitting. The available
placeholders are:

  `{file}`         `path/to/file.lua`
  `{line}`         `path/to/file.lua :L42`
  `{reviews}`      all Reviews rendered through `reviews.item`

Locations are spelled by the focused Tool's `format` hook; without one the path
and its `:L` suffix are joined by a space.

The `{reviews}` prompt is hidden while there are no Reviews.

FILES AND BUFFERS ~

The `files` and `buffers` Terminal actions pick several files or buffers and
type their references into the focused Agent without submitting: >

    require("vantage").setup({
      cli = {
        win = {
          keys = {
            { "<c-f>", "files", mode = "t", desc = "send file references" },
            { "<c-b>", "buffers", mode = "t", desc = "send buffer references" },
          },
        },
      },
    })

<
`files` lists files under the focused Agent's working directory (`fd`, then
`ripgrep`, then a built-in walk that skips `.git`). `buffers` lists listed
buffers whose file exists on disk, most recently used first; a modified buffer
is marked `[+]` because the Agent reads the on-disk version. Each chosen row is
typed as its path relative to the Agent's cwd, spelled by the Tool's `format`
hook (a gathered row has no position, so `loc` is nil) — no `@` unless you add
one — then `gather.join` decides the separator (default one per line), and a
trailing space follows the last reference. `fzf-lua` and `snacks` select
several rows at once (`<Tab>` marks, Enter sends the marked set or the row
under the cursor when none is marked); `native` sends one row at a time.
Claude's `@` lives in the hook: >

    claude = {
      cmd = { "claude" },
      format = function(file, loc)
        return "@" .. file .. (loc and (" " .. loc) or "")
      end,
    }

<

REVIEWS ~

`:Vantage review` adds a Review over the selection or current line.
`:Vantage review list` jumps to and edits Reviews; `:Vantage review clear`
removes them. Reviews live only in memory and are lost when the buffer unloads
or Neovim exits.

In the note window, `<Esc>` saves. An empty note deletes the Review. Send
Reviews with a prompt containing `{reviews}`, for example: >

    require("vantage").setup({
      prompts = { notes = "My notes:\n{reviews}" },
    })

<
`reviews.item` supports `{note}`, `{lines}`, `{code}`, `{file}`, `{start}`, and
`{end}`. The default is `"{lines} {note}"`; `{lines}` and `{file}` are spelled
through the Tool's `format` hook.

PICKERS ~

`picker` selects the UI used for Agent, kill, Review, and gathered file/buffer
lists:

  `"native"`   `vim.ui.select`; no preview and no list keys
  `"fzf-lua"`  fzf-lua; previews Agent output, Reviews, files/buffers
  `"snacks"`   snacks.nvim; previews Agent output, Reviews, files/buffers

With `fzf-lua` or `snacks`:

  `<c-g>`      toggle the Agent list's Group scope
  `<c-x>`      kill the selected Agent, or delete the selected Review

With a focused Agent, the Agent list opens scoped to its Group; its `<c-x>`
ignores the pinned `(focused)` row and Tool rows.
The `files` and `buffers` actions gather several rows at once under `fzf-lua`
and `snacks`, one row at a time under `native`.

KEYMAPS ~

The terminal buffer has filetype `vantage_terminal`. No keymaps are added by
default. Use `cli.win.keys` with `mode` set to `"n"`, `"t"`, or `"nt"`: >

    require("vantage").setup({
      cli = {
        win = {
          keys = {
            { "<c-q>", "toggle", mode = "t", desc = "hide/show terminal" },
            { "q", "toggle", mode = "n", desc = "hide/show terminal" },
            { "s", "switch", mode = "n", desc = "switch Agent" },
            { "p", "prompt", mode = "n", desc = "send prompt" },
            { "<c-f>", "files", mode = "t", desc = "send file references" },
            { "<c-b>", "buffers", mode = "t", desc = "send buffer references" },
          },
        },
      },
    })

<
`rhs` may be a Terminal action (`"switch"`, `"prompt"`, `"toggle"`, `"files"`,
`"buffers"`) or any value accepted by `vim.keymap.set`.

==============================================================================
5. COMMANDS                                    *vantage.nvim-commands*

                                                          *:Vantage*
`:Vantage`
    Show help.

`:Vantage toggle`
    Hide or show the terminal. With no terminal, pick an Agent and open it.

`:Vantage detach`
    Close the terminal. Agents keep running.

`:Vantage review`
    Add a Review over the current selection or line.

`:Vantage review list`
    Open the Review picker.

`:Vantage review clear`
    Remove all Reviews.

`:Vantage kill`
    Pick an Agent or Group and kill it.

`:Vantage status`
    Show clients and sessions.
